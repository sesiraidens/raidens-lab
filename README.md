## Sobre

Scripts interativos de calibracao com trackbars, conversao entre espacos de cor, gerador de ranges YAML e ferramentas de validacao.

---

## Ferramentas

| Ferramenta | Funcao |
|---|---|
| hsv_calibrator.py | Calibrador interativo HSV |
| lab_calibrator.py | Calibrador interativo LAB |
| camera_tester.py | Teste de camera com ranges |
| color_converter.py | Conversao RGB/HSV/LAB |
| range_validator.py | Validador de ranges |
